# Solar System Explorer

A website about the Sun, Moon, and planets. There are 10 pages, and each planet has its own look and something you can interact with.

To try it, open `index.html` in a browser and pick a planet from the menu.

Some things to check out:

- Change the orbit speed on the home page
- Try the Moon phase slider
- Switch Earth between day and night
- See what you would weigh on Mars
- Look through Jupiter's moons

The pages are in `pages`, the styles are in `css`, and the JavaScript is in `js`. The illustrations are in `images`.
